## The value in one paragraph per role

- **Reader:** a short, accurate reference for what Director-Driven Development is and how it works, enough to pick a framework and install it, or to apply the roles, the loop and the check in your own setup.
- **Director:** the answer to the question you have right now, in plain words, from your first task to the day something goes wrong.

## Roles

- **Reader:** anyone who wants to use AI coding agents to build software and stay in control of what gets built.
- **Director:** a reader running a project with a framework.
