# Where do I start?

<div class="kicker">Pick a framework, install it, answer the onboarding questions</div>

> Install the framework that fits what you are building, restart Claude Code, and let onboarding interview you. It ends with one commit for you to approve. Then ask for your first task.

## Short answer

1. **Pick the framework.** [Godot-Director](../frameworks/godot-director.md) for games, [App-Director](../frameworks/app-director.md) for apps, [SaaSAllTheThings](../frameworks/saasallthethings.md) for multi-tenant B2B SaaS on Azure. The [comparison page](../frameworks/index.md) sets them side by side.
2. **Install it.** Each framework page has an Install section with the steps. Onboarding works out whether the project is new, existing or an upgrade and agrees who owns what.
3. **Restart Claude Code,** so the commands load.
4. **Decide what to build.** Start a design session: [How do I decide what gets built, or change how something works?](decide.md)
5. **Get it built.** [How do I get things built?](build.md)
