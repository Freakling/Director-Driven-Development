# I already have a project. Can I use this?

<div class="kicker">Yes: onboarding reads your project instead of interviewing you from scratch</div>

> Yes. Onboarding works out whether the project is new, existing or an upgrade, reads what is already there, and ends with one commit for you to approve.

## Short answer

- **Any of the three frameworks installs into an existing project.** Install it the same way as into a new one: each framework page has an Install section ([Godot-Director](../frameworks/godot-director.md#install), [App-Director](../frameworks/app-director.md#install), [SaaSAllTheThings](../frameworks/saasallthethings.md#install)).
- **Onboarding reads the project.** Godot-Director and App-Director interview you or read the game or the code, and agree who owns what. SaaSAllTheThings reads the app, including its single-tenant habits and secrets, and writes the first stages of the roadmap into `TASKS.md`.
- **SaaSAllTheThings can assess first.** `saas-assessment` analyses an existing app without changing it: readiness with evidence, the roadmap by stage with rough effort, and the workshops to hold.
- **Features from before the framework come under a checklist.** A full round of the check by hand covers them: see [How do I check that what was built works?](check.md)
