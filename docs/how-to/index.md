# How-to

<div class="kicker">Step by step, for a first use</div>

> Each guide takes one skill and walks you through it, from nothing done yet to a result you can check.

The skill pages say what each command does. The guides say what you do: what to know before you start, what to type, where the files go, what the agent asks you, and what can go wrong.

Each guide describes only what is released, names the frameworks that ship its skill, and links to the skill page and the procedure for the details.
