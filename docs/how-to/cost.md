# It's costing more than I'd like

<div class="kicker">Small tasks on small models, and a few habits that keep the context small</div>

> Set the model for each task size with `/refresh-model-sizing`, then use the cost habits on the concept pages. Most of the savings are built in.

## Short answer

- **Sizing.** Every task has a size from XS to XL, and the size picks the model that builds it. `/refresh-model-sizing` writes the map into `AGENTS.md` after you confirm it. Run it when you set up a project and when new models come out. All three frameworks ship it.
- **Built-in savings.** A fresh context per task, lean instructions and records in files work without you doing anything: [Built-in cost savings](../concept/cost-built-in.md).
- **Your own habits.** Clearing between topics, smaller tasks and trimmed tools: [Cost tuning for developers](../concept/cost-tuning.md).
